2WhatsApp Channel Credentials

Pick one route. 2A is the official one we use for the GloAro office bot.

2A · Meta WhatsApp Cloud API RECOMMENDED

  • Business WhatsApp number — must not be active on the WhatsApp app
  • Phone Number ID
  • Business Account ID (WABA)
  • Access Token — system user with whatsapp_business_messaging + business_management
  • App Secret — verifies the webhook signature
  • Webhook Verify Token WE CREATE
  • Admin / partner access to their Meta Business Manager
  • OTP access on the number for verification

Gets: buttons, tappable list menus, templates, delivery status. Template approval needed for first contact; replies limited to a 24-hour window.

2B · UltraMsg (fallback)

  • Instance ID
  • Token
  • Phone in hand to scan the QR code
  • Callback secret WE CREATE

No Meta account, no number deletion, no 24-hour limit. But no buttons or list menus (numbered menus only), and it is an unofficial gateway — bulk messaging risks a ban.
