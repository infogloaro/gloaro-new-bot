Requirement Specification Document

1. Project Overview

Build a WhatsApp bot for GloAro to handle customer enquiries for GloAro Mart and GloAro Digital Network. The bot provides menu-based conversations, lead capture, PostgreSQL storage, Google Sheets integration and admin WhatsApp notifications.

The architecture should be scalable for future AI, CRM, campaigns, GloAro Tech and order tracking.

2. Initial Scope

Included in V1

  • WhatsApp Business API integration with a dedicated company WhatsApp number
  • Welcome message and main menu
  • GloAro Mart and GloAro Digital Network conversation flows
  • Lead capture, PostgreSQL storage and Google Sheets sync
  • Admin WhatsApp notification
  • Basic admin dashboard with customer & conversation history
  • Bot sessions, error handling, testing and production deployment

Deferred (Future Phases)

  • Advanced AI conversations
  • Marketing campaigns
  • Complex CRM and billing
  • Multi-tenant SaaS

8. Google Sheet Integration

Columns: Date & Time, WhatsApp Number, Name, Email, Business Name, Main Category, Subcategory, Product Category, City, Requirement, Status.

Use the Google Sheets API to append each lead, with proper error handling and retries.

9. WhatsApp Integration

Use the official Meta WhatsApp Business Platform / Cloud API.

GloAro ProvidesDeveloper Handles
Dedicated business mobile number, Meta Business account, WhatsApp Business account, required access & verification. Meta app configuration, API setup, credentials, webhook, message handling, bot integration and testing.

One dedicated GloAro business number is used for V1. API tokens must never be exposed in frontend code.

10. Webhook

  • GET /webhooks/whatsapp — verification
  • POST /webhooks/whatsapp — message events
Customer → WhatsApp → Meta → Webhook → NestJS Backend → Bot Engine → Response

Webhook events must be logged and processed idempotently to prevent duplicate messages and duplicate leads.

16. What the Developer Will Handle

Frontend, backend, database, bot engine, WhatsApp API, webhook, Google Sheets API, lead capture, admin notification, admin dashboard, authentication, validation, error handling, testing and deployment.

17. Final Architecture

Customer → WhatsApp → Meta WhatsApp Platform → Webhook → NestJS Backend → Bot Engine → PostgreSQL
  • Bot Engine branches into GloAro Mart and GloAro Digital Network.
  • Leads flow to Google Sheets and Admin WhatsApp.
  • React Admin Panel connects to the backend.

18. V1 Completion Criteria

  • Customer can message the GloAro WhatsApp number and the welcome message works
  • All GloAro Mart and Digital Network flows work end to end
  • Required details are collected correctly
  • Leads are saved to PostgreSQL and Google Sheets
  • Admin receives the WhatsApp notification
  • Admin can view and update leads
  • Conversation history is stored
  • Invalid inputs are handled gracefully
  • Production WhatsApp works reliably
  • Webhook is secured and tested
